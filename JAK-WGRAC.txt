2. WGRANIE NA GITHUB PAGES — KROK PO KROKU
------------------------------------------------------------------
  a) Rozpakuj ZIP. Na JEDNYM poziomie muszą leżeć: index.html, style.css,
     skrypt.js, config.js, robots.txt, sitemap.xml, .nojekyll, assets/

  b) github.com → New repository → nazwa np. mszana-odpady-tura-2 → Public → Create

  c) Na stronie pustego repozytorium: "uploading an existing file"
     → przeciągnij CAŁĄ ZAWARTOŚĆ folderu (pliki i katalog assets), nie folder nadrzędny
     → Commit changes

  d) Settings → Pages → Source: "Deploy from a branch"
     → Branch: main, folder: / (root) → Save

  e) Odczekaj 1–2 minuty. Adres:
     https://<twoj-login>.github.io/<nazwa-repo>/

  f) Wejdź i sprawdź: nagłówek, trzy karty dokumentów (01/02/03) rozwijają się,
     zrzut protokołu widać w karcie 02.

------------------------------------------------------------------
3. WAŻNE: .nojekyll
------------------------------------------------------------------
  Plik zaczyna się kropką, więc Windows/macOS może go nie pokazać przy
  przeciąganiu i wiele narzędzi ZIP pomija go domyślnie.
  Jeśli po wgraniu strona się nie otwiera — sprawdź, czy .nojekyll jest
  w repozytorium. Jeśli nie ma: Add file → Create new file → nazwa ".nojekyll"
  → zostaw puste → Commit.
